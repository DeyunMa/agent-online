# 2026-09-06 本地可靠性加固

本轮由三个子智能体并行修复并交叉审查，主任务集成上下文和工程门禁。
只修改本地工作树；未提交、未部署、未操作远程资源，未运行付费 E2B/Gemini E2E。

## 行为变化

- Preview 内容响应强制 `sandbox allow-scripts`，直接导航和 iframe 都隔离同源存储。
- 真实 Workflow Run 将最近可见 Message 装入瞬时 prompt：最多 20 条、64 KiB JSON
  历史，保留角色、标注省略，并提醒先检查当前工作区。不是原生 Agent session resume。
- Pi 以完整最终 assistant 消息提取回复；Goose 在所有工具尝试后清除旧的中间文字。
- Agent JSONL 单记录最多 1 MiB，最终回复最多 256 KiB；E2B 进程累计输出最多
  32 MiB，待消费最多 2 MiB / 4096 事件，超限断流并终止。
- 上传通过沙箱侧 exclusive create，原子拒绝同名目标和符号链接组件。
- 仅为 Archify 生成的精确 HTML 文件关闭业务 lint，架构 JSON 保留格式门禁。

## 验证

`rtk pnpm check` 全部通过：303 项单元测试、8 项真实 D1 测试（隔离环境应用全部迁移）、
8 项 Chromium 测试，以及导入边界、凭据扫描、lint、格式、类型、构建和产物安全检查。
相对审计基线新增 34 项单元测试、1 项 D1 测试、2 项浏览器测试。

针对测试包含真实本地 Python 文件系统同名并发、符号链接拒绝、stdin 失败清理、
跨 Project 历史排除、NUL 内容完整性、UTF-8 字节限额、协议失败和慢消费者输出洪泛。
Preview 浏览器回归使用生产 CSP 和模拟 Provider 内容，不代表远程 E2B 验收。

## 剩余边界

- 上传与 Run/Terminal 的活动检查仍按 ADR-0011 保持尽力一致；磁盘写失败可能留下
  新建的部分文件，不承诺文件事务回滚。
- 历史预算按字节约束，不是模型 tokenizer 的精确 token 预算；模型实际续改质量需要
  后续固定任务评测。旧消息不意味着临时工作区文件仍然存在。
- 输出密集任务可能触发新增限额，真实模板/模型链路需要另行验收。
- 本轮未增加 Run 级费用限额、应用级速率限制、实时工具进度或前端拆包；客户端主包
  大小警告仍存在。这些不应被视为已经实现。
