# 2026-07-26 D3 受控 Terminal 纵切

> 状态：代码、迁移、单元/API 测试、类型检查和生产构建已完成；远程 Preview 迁移、部署与真实浏览器 PTY E2E 待执行。
> 关联：[ADR-0005](../adr/0005-controlled-project-terminal.md) · [运行时边界](../architecture/02-sandbox-runtime.md) · [Preview 部署](../setup/preview-deployment.md)

## 1. 本阶段目标

在不引入第二个 Worker、Durable Object、R2、终端历史或 Provider 直连的前提下，让登录用户从 Project Inspector 使用当前 E2B 沙箱的真实 `/workspace` PTY。

## 2. 已实现

### Runtime 与应用层

- 新增独立 `SandboxTerminalRuntime` / `SandboxTerminalSession` capability，不扩张 AgentRuntime 协议。
- `E2BSandboxRuntime` 使用 E2B PTY API 实现 create、binary output、input、resize、kill 和自然退出。
- `ProjectTerminalService` 固定 `/workspace`、20–240 列、5–100 行、单条 16 KiB input 和 30 分钟会话上限。
- E2B 输出使用 256 KiB 有界待消费队列，单会话累计输出上限 8 MiB；超限会进入受控关闭，不允许 `yes` 一类命令无界占用 Worker 内存。
- AgentRun 创建编排已从 Hono 收入 `CreateAgentRunService`，Terminal 没有继续扩大 `project-api.ts`。

### D1 与并发

- migration `0004_terminal_sessions.sql` 新增每 Project 最多一行的临时 Terminal 占用。
- 该表只保存 Project/Lease 关联、私有 sandbox/PTY reference 和过期时间；关闭即删除，不保存任何终端内容。
- AgentRun INSERT trigger 与 Terminal claim 双向保证一个 Project 的 AgentRun/Terminal 互斥。
- Files、手动停止、Run idle cleanup 和 Terminal idle cleanup 都在 D1 条件更新中检查活动 Terminal。
- `expires_at` 不再自动放开互斥；claim 同时校验 Lease `updated_at/provider_ref`，避免并发 Stop 后复活旧 Provider reference。
- 每个 session 记录所属 Provider sandbox；只在该实例一致且 PTY 已确认终止后释放。kill 失败时先停止整个 sandbox；仍失败则保留锁并把 Lease 隔离为 `failed`。

### WebSocket 与浏览器

- 新增 `GET /api/projects/:projectId/terminal` 同源 WebSocket。
- 升级前校验 Better Auth、精确 `Origin` 和 Project 所有权；升级后才创建 Provider PTY。
- 自管 Cloudflare `WebSocketPair` 在 10 秒 attach deadline、原始 frame 字节上限和最多 32 条串行消息队列内工作；异步断线清理由 `executionCtx.waitUntil()` 托管。
- 公共协议只有 `attach/input/resize/close` 与 `ready/output/closed/error`；不返回 E2B sandbox ID、PTY PID、内部端口或 Key。
- Project Inspector 按服务端 `terminalEnabled` capability 启用 Terminal tab。
- xterm 与 fit addon 按需拆包；用户点击 Connect 才启动沙箱。切换 inspector tab 保持连接，切换 Project/离开页面关闭。
- Terminal 连接期间 New Run、Composer、Files 和 Stop sandbox 都在 UI 禁用；D1 仍是可信互斥边界。

### 资源回收与构建安全

- Terminal 关闭后在一个 D1 batch 中释放临时行并标记 Lease idle。
- `terminal-expiry-<sessionId>` Workflow 是 30 分钟上限的 durable owner；Worker timer 只做同进程内的快速关闭。
- `terminal-idle-<sessionId>` Workflow 等待现有 10 分钟 TTL，并按释放时的 Lease `updated_at` 防止误停新活动。
- `pnpm build` / preview build 先清理 `dist`，Cloudflare 插件构建模式不序列化本地 Secret，构建后门禁拒绝 `.dev.vars*` 和 `.env*`。
- xterm 生成独立懒加载 chunk，不增加首屏同步执行依赖。

本地浏览器注册 smoke 暴露的是环境事实：`.dev.vars` 当前 `BETTER_AUTH_URL` 不信任 `http://127.0.0.1:5173`，Better Auth 正确返回 403；它不是 Terminal 代码失败。后续本地浏览器应使用与 `BETTER_AUTH_URL` 完全一致的 origin，或直接在私有 Preview 完成真实 PTY E2E。

## 4. 远程验收清单

1. 应用 `0004_terminal_sessions.sql` 到 Preview D1，再部署同一提交。
2. 登录 allowlist 用户，确认 `/api/capabilities.terminalEnabled = true`。
3. 新建 Project，连接 Terminal，执行 `pwd` 和创建唯一测试文件。
4. Terminal 活动时验证 AgentRun、Files 和 Stop sandbox 被拒绝；D1 只有一条临时 session 且浏览器看不到其私有字段。
5. 关闭 Terminal，确认 D1 临时行删除、Lease idle；Files 能读取测试文件。
6. 启动 Pi Run 读取或修改同一文件，证明 Terminal/Agent 共用唯一 `/workspace`。
7. 验证 resize、非零退出、显式 Close、浏览器断线和重新连接。
8. 用桌面 `1440x900` 与移动 `390x844` 检查无溢出、遮挡和状态跳动。
9. 临时缩短 idle TTL 或等待正式 TTL，确认 Terminal cleanup Workflow 不误停新活动，并最终清除未复用沙箱。

## 5. 剩余边界

- Terminal 不支持 reconnect/detach、多终端、协作或 transcript；浏览器关闭即结束 PTY。
- Usage 仍只聚合 AgentRun，不记录 Terminal 命令或长期时长事实。
- 标准 Worker WebSocket 在会话期间保持活动；长期大并发前需要重新评估 Worker 与 E2B 连接成本。
- 下一纵切是受控 Preview：固定端口、同源代理、进程/端口生命周期和不泄露 Provider URL。Changes 排在其后。
