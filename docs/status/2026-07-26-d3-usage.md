# 2026-07-26 D3 当前用户 Usage 纵切

> 状态：代码、自动化测试、本地 D1 和真实浏览器验收已完成；尚未发布到 Cloudflare Preview。
> 范围：当前登录用户的全量 AgentRun 用量，不包含维护者视图、配额、价格或计费。

## 1. 本阶段结论

本阶段直接聚合已有 `agent_runs`，没有新增 D1 表、迁移、外部服务或环境变量。公开接口为认证后的 `GET /api/usage`，返回：

- `scope: "all_time"`；
- 当前用户全部 Run 的 `totals`；
- 按 Project 分组的 `projects`；
- 按 AgentRuntime 分组的 `agentRuntimes`。

每组指标都包含 Run 数、输入 token、输出 token、总 token、模型请求数和沙箱时长。查询不按状态过滤，因此失败、取消、超时或非终态 Run 的已记录真实消耗也会计入。该读数用于产品可见性，不是账单或价格估算。

## 2. 实现边界

```text
React UsagePage
  -> GET /api/usage
  -> Hono usage-api（认证与响应映射）
  -> UserUsageQuery / UserUsageService
  -> D1UserUsageRepository
  -> agent_runs + projects
```

- Usage 路由独立于 `project-api.ts`，没有继续扩大 Project 路由编排。
- D1 在一个 batch 中执行总计、Project 分组和 AgentRuntime 分组三个只读查询，全部绑定服务端认证得到的 `user_id`。
- 响应不包含 `user_id`、`provider_ref`、Provider sandbox ID、进程引用、内部端口或 Key。
- React Query 在 Run 创建、取消和终态收敛后使 Usage 缓存失效；页面仍提供显式刷新。
- 桌面入口位于 Project 左栏；移动端左栏折叠后由顶部图标进入。
- loading、empty、error、refresh 和 populated 状态都使用真实 API 数据。

## 4. 未实现与风险

- 当前只有 all-time 读数，没有日期筛选、时间序列、CSV 或分页。
- 没有 `/api/admin/usage`、每用户并发上限、配额和异常阈值。
- 没有价格、套餐、额度、订阅或支付对象；未来商业化需要独立领域设计。
- 聚合是请求时读取 D1 的当前值，不是不可变账本；活动 Run 的读数可在刷新后增长。
- 本阶段尚未部署到 Cloudflare Preview，因此远程 D1 隔离和生产构建 UI 仍需在下一次批准的部署中复验。
