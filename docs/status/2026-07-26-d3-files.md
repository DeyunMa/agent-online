# 2026-07-26 D3 只读 Files 纵切

> 状态：本地实现、自动测试、桌面/移动浏览器验收和 Cloudflare Preview 真实 E2B 验收均已完成。

## 1. 完成范围

- `SandboxRuntime` 增加文件能力合同，并区分 Lease 级与 Runtime 实例级文件连续性。
- E2B Adapter 支持目录列表和字节读取；Provider 文件错误映射为平台错误。
- `ProjectFilesService` 只附着 Project 现有 Lease，不因浏览创建沙箱。
- 同源 API 提供目录列表和 UTF-8 文本读取；响应不含 Provider ID、绝对路径、端口或 Key。
- Project Inspector 启用 Files 标签，包含 loading、空目录、无沙箱、活动 Run、错误、目录、面包屑和文本预览状态。
- 在本纵切验收时，Terminal、Preview 和 Changes 仍禁用；三者随后分别按
  ADR-0005/0006/0007 完成。

API：

| 路径 | 作用 |
| --- | --- |
| `GET /api/projects/:projectId/files?path=` | 列出 `/workspace` 下的受控相对目录。 |
| `GET /api/projects/:projectId/files/content?path=` | 读取受控相对路径的 UTF-8 文本。 |

## 2. 安全与产品限制

- 路径最多 512 字符、32 层；拒绝绝对路径、反斜线、控制字符、空段、`.`、`..` 和 `.git`。
- 逐层检查并拒绝符号链接；目录最多返回 500 项。
- 文件最多 256 KiB；拒绝非法 UTF-8、NUL 和明显二进制内容。
- Project 有非终态 Run 时不读取，以减少与 Agent 写文件的竞态。
- 沙箱停止、过期或 Provider 不可达时返回明确不可用/服务错误；不自动重建。
- fake Runtime 的 handle 和文件只在一次内存实例中存在，不能跨 Worker 请求，因此公共 Files 明确不可用。测试中使用显式 Lease 级 memory fixture，不把 fake 伪装成持久沙箱。

活动 Run 检查、Lease 读取和外部文件读取并非原子操作；逐层符号链接检查与最终读取也存在 TOCTOU。第一版将 Files 定义为个人项目下的尽力一致只读视图，不宣称严格并发安全。

- API 测试覆盖 Project 所有权、目录/文本响应以及 Provider 信息不泄露。
- application/runtime 测试覆盖路径逃逸、`.git`、符号链接、二进制、超大文件、活动 Run、停止 Lease、fake 跨请求语义和 E2B 元数据映射。

## 4. 基础设施影响

本纵切没有新增 D1 表、迁移、R2、Worker、外部服务或环境变量。Project 文件仍只有当前沙箱一份，停止后允许丢失。
